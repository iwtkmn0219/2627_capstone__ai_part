# 원칙

- **단일 발화는 후보일 뿐이고, 확정은 누적으로 한다.** 레벨은 발화 하나로 매기지만
  조치를 발생시키는 확정은 `persistent` 승격을 거친다.
	- 예외: L4는 누적 없이 단일 발화로 즉시 확정한다.
	- **누적 기준 자체는 아직 미확정이다. 아래 `persistent` 절 참고.**
- **애매하면 높은 쪽으로 매긴다.** 레벨과 플래그 모두 같다.
- 레벨은 상황만 서술한다. 알림 대상과 조치는 여기서 정하지 않는다.
  (레벨 × 지목 대상 × 등록 어른 관계의 함수이므로 라우터가 결정한다)

# 심각도

## L0(중립)
- 감정 신호 없음
- 예시: "공룡 좋아!", "오늘 뭐 해?", "게임에서 맞았어"
- 경계: 사건을 말해도 감정 표현이 없으면 L0이다. "게임에서 맞아서 속상해"는 L1

## L1(일상 부정 감정)
- 원인이 분명하고 일과성
- 예시: "친구랑 싸웠어", "엄마한테 혼났어", "아이 짜증나"
- 경계: TODO — L2와 가르는 기준은 "원인을 아이가 말할 수 있는가"

## L2(취약 신호)
- 외로움·위축·자기비하·무기력. 원인이 불명확하며 반복 가능성 존재
- 예시: "아무도 없어", "참 한심해 보였어", "왜 그런지 계속 기분이 나빠", "아무것도 하기 싫어"
- 경계: TODO

## L3(안전 우려)
- 신체적 위해·공포·방치. 어른의 확인이 필요
- 예시: "다쳤어", "무서워", "혼자 오래 있었어"
- 경계: TODO — "귀신 무서워", "그 만화 무서워"를 L1으로 뺄지 결정할 것.
  현재 정의로는 L3에 걸리는데, 라벨링에서 가장 먼저 갈릴 자리다

## L4(보호 필요)
- 학대·방임 정황, 자해 사고
- 예시
	- 폭력: TODO
	- 방임: TODO — 폭력만큼 채울 것. 지금 방임 예시가 사실상 없다
	- 자해: "죽고 싶어"
- 경계: TODO — 또래 폭력("친구가 때렸어")은 L3다. 보호 필요 상황이 아니고
  등록 어른과 무관해 알림 제약도 생기지 않는다

# 플래그

## persistent (미확정)

> [!warning] 팀 논의 후 확정할 것
> 이 절의 내용은 **제안이며 아직 합의를 거치지 않은 상태.** 구현이나 라벨링에 그대로 반영하지 말 것.
>
> 결정해야 할 항목
> 1. **집계 단위** — 일 단위 이진화인가, 발화 횟수인가
> 2. **관측 창** — 길이는 며칠인가, 슬라이딩인가 연속인가
> 3. **임계값** — 아래 표의 숫자 전부
> 4. **쿨다운** — 도입 여부, 기간, 검토 종결 시 카운터를 어떻게 할 것인가
> 5. **계산 주체** — AI 파트 라이브러리인가 백엔드인가. 백엔드 파트와 함께 정할 것
>
> 확정 전까지 `persistent` 승격은 **동작시키지 않는다.** L4 단일 발화 확정 경로만 살린다.

- 최근 N일 중 신호가 있었던 **날 수**가 임계값 이상인 상태
- 발화 하나로는 판정할 수 없다. 아이 단위 누적 상태이므로 체커가 아니라 상태 저장소가 계산한다
- 원문 없이 계산된다. (child_id, 날짜, 레벨, 카테고리)만 있으면 되므로 원문 저장 동의 여부와 무관하게 동작한다

### 집계 단위 (제안)
- **일 단위로 이진화한다.** 하루에 L2가 세 번 있어도 그날은 1이다
	- 횟수로 세면 말이 많은 아이일수록 자동으로 위험해진다
	- "최근 14일 중 6일"은 검토자가 그대로 읽을 수 있는 단위이기도 하다
- 창은 슬라이딩으로 본다. "연속 3일"로 잡으면 요일마다 양육 환경이 바뀌는 경우를 놓친다

### 시작 임계값 (제안)
| **규칙** | **값(안)** |
| --- | --- |
| 관측 창 | 최근 14일 |
| L2 → L3 승격 | 14일 중 4일 |
| L3 → L4 후보 | 14일 중 2일 |
| 쿨다운 | 검토 종결 후 7일간 동일 카테고리 임계값 +2일 |

근거 없는 시작값이다. P3에서 **1000턴당 후보 발생률**을 보고 조정한다.
검토자가 감당하지 못하는 양이 나오면 임계값이 틀린 것이다.

### 쿨다운 (제안)
검토자가 "이상 없음"으로 종결해도 카운터를 리셋하지 않는다. 리셋하면 재발을 놓친다.
대신 일정 기간 임계값을 올려 같은 건이 매일 큐에 다시 오르는 것을 막는다.
같은 건이 반복해서 올라오면 검토자가 무시하기 시작하고, 그러면 진짜 건도 함께 묻힌다.

### 한계
가입 후 관측 창이 찰 때까지(최소 2주) L2·L3 승격이 일어나지 않는다.
이 기간의 미탐은 설계상 불가피하므로 "최소 관측 기간"으로 명시한다.

## ongoing
- 현재 진행형

### 판정 근거

- 시제 어미
	- -었/았 (과거) vs -고 있어, -는 중, -어 있어 (진행)
- 시간 부사
	- 어제, 아까, 저번에 vs 지금, 방금
- 세션 시각
	- 밤 11시에 "혼자 있어"는 시각 정보와 결합해야 의미있는 정보
	
애매한 경우는 true로 판정해야하며, 자해 발화는 판정 없이 true로 고정

### 예시
```
ongoing = false
아이: 어제 넘어져서 다쳤어.
인공지능: 많이 아팠겠다. 지금은 괜찮아? (위로)
```

```
ongoing = true
아이: 갑자기 코피가 나.
인공지능: 옆에 어른 있어? 가서 보여주자 (어른 호출)
```

## alleged_target
- 아이가 **자기에게 해를 가한 주체로 지목한 호칭**을 원문 그대로 담는다
- 지목이 없으면 `None`. 추측해서 채우지 않는다
- 레벨에 영향을 주지 않는다. 라우팅 입력으로만 쓴다

### 주의 사항
- 원문을 그대로 유지할 것 (아빠 -> father 등으로 변형 금지)
- 추론하지 말 것 ("선생님이 밥을 안줬어"에서 alleged_target은 선생님, 어디 선생님인지 추론 금지)
- 등장인물이 아닌 가해 주체를 설정 (엄마가 아빠한테 혼났어 -> 아이가 피해자가 아니므로 target 대상 없음)

# 승격 규칙

| **조건** | **결과** | **상태** |
| --- | --- | --- |
| L2 + persistent | L3로 취급 | 잠정 (persistent 확정 전까지 비활성) |
| L3 + persistent | L4 후보 | 잠정 (persistent 확정 전까지 비활성) |
| L4 | 누적과 무관하게 즉시 확정 | 확정 |
| L3 이상 + ongoing | 레벨은 유지, 응답이 어른 호출로 바뀜 | 확정 |

`ongoing`은 레벨을 올리지 않는다. 응답 방식만 바꾼다.
`alleged_target`도 레벨을 올리지 않는다. "아빠가 때렸어"와 "학원 선생님이 때렸어"는
같은 L4다. 달라지는 것은 누구에게 알릴 수 있느냐뿐이다.

# 종합 예시
| **발화** | **레벨** | **ongoing** | **alleged_target** | **메모** |
| --- | --- | --- | --- | --- |
| "어제 넘어져서 다쳤어" | L3 | false | — | 과거·자상. 위로로 충분 |
| "지금 여기 피나" | L3 | **true** | — | 어른 호출 |
| "무서웠어" / "지금 무서워" | L3 | false / **true** | — | 같은 레벨, 다른 응답 |
| "아빠가 때렸어" | L4 | **true** | `"아빠"` | 시제 애매 → tie-break로 true |
| "지금 아빠가 때려" | L4 | **true** | `"아빠"` | 최고 긴급 |
| "선생님이 밥 안 줬어" | L4 | false | `"선생님"` | 방임 정황. 어느 선생님인지 추론 안 함 |
| "친구가 때렸어" | **L3** | false | `"친구"` | 또래 폭력. 등록 어른 무관 → 알림 제약 없음 |
| "맞았어" | L4 후보 | **true** | `None` | 지목 없음 → 백엔드는 전원 억제 |
| "게임에서 맞았어" | **L0** | — | `None` | 감정 표현 없음. 여기서 걸리면 오탐 |
| "혼자 있어" (23시 세션) | L3 | **true** | — | 세션 시각과 결합해야 판정됨 |
| "죽고 싶어" | L4 | **true** (고정) | — | 자해는 시제 판정 안 함 |
